Sistem Altyapısı & Güvenlik Bilgisi

M. Ali Yıldırım & Mali Academy Altyapı Standardı

⚡ Hosting & SSL Sertifikası

Güvenli, kesintisiz ve küresel içerik dağıtım ağı (CDN) sağlayan GitHub Pages / Serverless altyapısı. Tüm bağlantılar 256-bit SSL (HTTPS) ile uçtan uca şifrelenmektedir.

🔒 Veritabanı & Kimlik Doğrulama

Kullanıcı ve proje verileri Google Cloud & Firebase Auth / Cloud Firestore üzerinde saklanır. API istekleri HTTP Referrer kısıtlamaları ve Row-Level Security (RLS) ile koruma altındadır.

🛠️ Modern Web Teknolojileri

Modern Vanilla JavaScript (ES6+), HTML5, CSS3 & Tailwind mimarisi. Serverless API entegrasyonları (WebRTC / EmailJS) ve yüksek hızlı duyarlı tasarım.

⚖️ Gizlilik & Şeffaflık Standartları

Kişisel verileriniz asla 3. taraf kurumlarla paylaşılmaz. Tüm yönetim eylemleri kriptografik SHA-256 doğrulama protokolleri arkasında güvenle tutulur.
